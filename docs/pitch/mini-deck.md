# Mini deck (teaser) — 10 slides

Purpose: read in 3 minutes without you in the room; earn the meeting where the technical deck is shown. Last slide hands off to it.

| # | Slide | Content |
| --- | --- | --- |
| 1 | **Data Dealer** | The verified data supply chain for AI. Real data from paid people, expanded into synthetic data, sold with proof. |
| 2 | Problem | AI teams must now disclose where training data came from (EU AI Act since Aug 2025, enforced from Aug 2026; California AB 2013 since Jan 2026). Bad sourcing costs billions ($1.5B Bartz settlement, Jul 2026). Most data on the market can't prove its origin. |
| 3 | Solution | Every dataset ships with a signed manifest: who contributed, what they agreed to, every transformation, every AI model that touched it. Anyone can verify it publicly. |
| 4 | How it works | One-line flow: Contributors → Verification → Synthesis → Eval panel → Attestation → dataset → Buyers. (Image: the PFD, simplified.) |
| 5 | Why now | Disclosure laws in force; agent buyers arriving via MCP and x402; category validated (Protege $30M a16z, Human Native → Cloudflare, Gretel → NVIDIA). |
| 6 | Business model | Dataset sales, buyer-funded bounties, verify & compliance API (recurring), exclusive licenses. Repeat sales carry no new compute. |
| 7 | Traction | [Fill from pilots: LOIs, first dataset sold, contributors paid, time to match.] |
| 8 | Moat | Verified contributor network + provenance graph + compliance exports that buyers file with regulators. |
| 9 | Team | Astra + partner. [Roles, relevant experience.] |
| 10 | The ask → technical deck | Raise amount, use of funds, milestones. "The technical deck shows the full system, guardrails and live audits." |

Design: black ground, money green and data red as in the dashboard, one idea per slide, no paragraphs over two lines.
